# Browser Support

| 브라우저     | 수신 UI/WebRTC | 대용량 디스크 스트리밍 | 비고                                           |
| ------------ | -------------- | ---------------------- | ---------------------------------------------- |
| Chrome 최신  | 지원           | 지원                   | 권장                                           |
| Edge 최신    | 지원           | 지원                   | 권장                                           |
| Safari 최신  | 조건부         | 제한                   | File System Access API 제약, 512 MiB 초과 차단 |
| Firefox 최신 | 조건부         | 제한                   | File System Access API 제약, 512 MiB 초과 차단 |

모든 브라우저에서 기능을 런타임 감지합니다. 공유 총 크기가 512 MiB 이하이면 macOS 보호 폴더 권한을 별도로 요청하지 않고 브라우저의 기본 다운로드 위치에 저장합니다. 512 MiB를 넘는 대용량 공유에서만 File System Access API로 파일 또는 전용 폴더를 선택해 디스크에 바로 기록합니다. 디스크 스트리밍을 지원하지 않는 브라우저에서는 전체 Blob을 RAM에 올리지 않고 명확한 안내와 함께 다운로드 시작을 막습니다.

네트워크 지원은 브라우저보다 NAT·방화벽의 영향을 크게 받습니다. 기본은 STUN direct P2P이고, 운영자가 TURN을 구성하고 송신자가 Relay를 허용한 공유만 Relay 후보를 사용합니다.
